# Neovim Reference

Raycast extension - a quick reference for Neovim commands.


## Documentation

- https://developers.raycast.com/basics/create-your-first-extension

## Installation

- Clone repository
- cd to `./neovim-reference` and run `npm install && npm run build`
- Use "Import Extension" Raycast command
- Type "Neovim Reference" to open extension in Raycast
